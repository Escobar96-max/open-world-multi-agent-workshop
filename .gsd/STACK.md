# Project Agent World: Tech Stack

- **Backend Runtime**: Python 3.11+ / Python 3.14 (FastAPI, Uvicorn, Pydantic v2)
- **Security & Crypto**: PyJWT, cryptography, SHA-256 dynamic Proof-of-Work
- **Database & Memory**:
  - Persistent Obsidian Markdown Vault (`/vault/`) with PyYAML frontmatter
  - Neon Serverless PostgreSQL with `pgvector`
- **Spatial Simulation**: Antigravity 2D Cartesian Engine with Euclidean distance checks
- **Testing**: pytest, pytest-asyncio, httpx / starlette testclient
- **Automation & Agent Frameworks**: GSD (Get Shit Done), Ralph autonomous execution loop, CodeRabbit CLI
- **Operator Interfaces**: Operator C2 API, Web Deck UI, Telegram Bot API
- **Edge Deployment**: Cloudflare Zero-Trust Tunnel
